# WeChat Writing Style Skills

AI Pioneer 的公众号写作风格 Skill 仓库。

这里收录的不是“仿写提示词”，而是从知名公众号样本中拆出的可复用写作机制：选题方式、标题结构、开头钩子、信息密度、论证节奏、语言习惯与结尾设计。目标是写出同类阅读体验的原创文章，不复刻原句，也不冒充原账号或作者。

## 收录原则

- 每个风格 Skill 都必须基于可核查的公开样本，不靠印象总结。
- 区分账号的稳定风格与单篇文章的偶然写法。
- 保留来源、样本日期和适用题材，避免风格过期或误用。
- 只抽象方法，不复制标志性句子、段落或个人经历。
- 输出必须服从事实与用户观点；风格不能覆盖内容真实性。
- Skill 应通过 `quick_validate.py`，且至少用一篇未参与分析的文章做盲测。

## 目录约定

```text
<skill-name>/
├── SKILL.md
├── agents/openai.yaml
└── references/
    ├── style-profile.md
    └── source-notes.md
```

具体公众号的 Skill 建议使用小写英文或拼音命名，并在描述中写清适用场景。样本原文原则上不整篇复制进仓库；只保存链接、日期、标题和必要的短摘录或分析笔记。维护者明确指定收录的完整原文，归档到独立的 `authors/<author>/originals/` 栏目，并记录作者、来源与整理方式。

## 新增一个公众号风格

1. 选取至少3篇具有代表性的公开文章；样本不足时，将结论标为“暂定”。
2. 使用 `wechat-style-analyzer` 生成风格画像。
3. 把稳定规则写进 `SKILL.md`，把样本依据放入 `references/source-notes.md`。
4. 用未参与分析的新主题做一次测试，检查是否只学到表面口癖。
5. 验证 Skill 后再提交。
